PSoXide Demo Disc (PSX)
=======================

The standard disc carries twelve programs: the current new-engine Cortex
Ignition, Cortex Ignition Legacy, VoXide, NitroXide, the Celeste Classic
Collection, PSXcel, GH-PSX, Breakout, Space Invaders, Magikaaaaarp Pong, the
hardware test suite, and Quake Shareware. The private Half-Life pressing adds
Half-Life as the thirteenth program. Everything on it is native PlayStation
software built with the PSoXide Rust SDK.

The standard disc keeps both work-in-progress Cortex cards behind the Konami
unlock. The Half-Life pressing shows both cards directly. Cortex Ignition is
the active Quake Units Arena project on the current engine; Cortex Ignition
Legacy preserves the original grid demo on its frozen engine.

To run:
  - Boot the .cue in a PS1 emulator (PSoXide, DuckStation, or PCSX-Redux), or
  - burn it to a CD-R and run on a modchipped console.

In the menu: D-pad to browse, Cross to launch. Each program returns to the
menu on reset.

Menu music: four tracks by Just Music
(https://www.youtube.com/@Just-Music-Beats), used with the artist's
permission. Non-commercial, do not redistribute the audio separately.
